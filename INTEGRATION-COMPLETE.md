## 📊 Technical Details

### Responsive Breakpoints:
- **320px+** (Small phones): Single column, stacked
- **640px+** (Large phones): 2 columns where appropriate
- **768px+** (Tablets): 2-3 columns
- **1024px+** (Desktop): Full 4-column grid

### Touch Targets:
- Buttons: `min-h-[44px]`
- Form inputs: `min-h-[44px]`
- Category buttons: `min-h-[88px]`
- Links: `min-h-[44px] flex items-center`

### Typography:
- Base font: 16px (prevents iOS zoom)
- Responsive: `text-4xl md:text-5xl`
- Line heights: Optimized for readability

### Forms:
- Inputs: 100% width on mobile
- Validation: Clear error messages
- Camera access: Enabled for photos
- File upload: Works on mobile browsers
